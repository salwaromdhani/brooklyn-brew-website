
# BROOKLYN BREW | Coffee Shop Website

A modern and elegant website designed to showcase the identity and experience of a coffee shop.

## Overview

**BROOKLYN BREW** is an academic web development project focused on building a structured, user-friendly website for a coffee shop. It highlights the brand's identity and organizes key information through a clean and engaging interface.

The project demonstrates practical front-end development skills, attention to detail, and the ability to structure a multi-section website.

## Key Features

- **Home Section** — A welcoming introduction to the coffee shop.
- **About & Details** — Dedicated sections presenting the café and its concept.
- **Location & Contact** — Practical information to help visitors connect with the café.
- **Responsive Design** — An interface designed with usability in mind.
